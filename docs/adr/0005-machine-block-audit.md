# ADR-0005 — Audyt MachineBlock zawsze obowiązkowy

**Status:** Accepted  
**Stan ustaleń:** 2026-10-16

## Kontekst

Powód i Issue mogą zależeć od polityki konkretnego zakładu.

## Decyzja

Każdy Block i Release zachowuje maszynę, aktora oraz czas; nie usuwamy historycznych rekordów.

## Konsekwencje

Szybka blokada jest możliwa, lecz nigdy bez śladu audytowego.
