# ADR-0004 — Uprawnienia inne niż kwalifikacje

**Status:** Accepted  
**Stan ustaleń:** 2026-10-16

## Kontekst

Autoryzacja w systemie i kwalifikacje fizyczne operatora są różnymi pojęciami.

## Decyzja

Rozdzielić Permission i Qualification; nie kodować uprawnień tylko na podstawie roli managera.

## Konsekwencje

Możliwość konfigurowania praw per zakład; egzekwowanie kwalifikacji przy starcie poza MVP.
